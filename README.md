# Boom & Bust companion app

One iPad per table, used beside the printed board game. Students roll real dice, move real pieces and hand over real paper money; the app tracks the game and does every calculation, itemised on screen.

- `SPEC.md`: what the app does and how the rules work (generated from `SPEC.template.md` by `gen_data.py`).
- `game-data.json`: every game number (generated by `gen_data.py`; run `npm run data` after editing it).
- `DECISIONS.md`: rule and design decisions beyond the spec.

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Dev server on http://localhost:5173 |
| `npm test` | Rules engine tests (Vitest), including SPEC section 11 |
| `npm run build` | Type-check and build the offline-ready PWA into `dist/` |
| `npm run preview` | Serve `dist/` locally |
| `npm run assets` | Re-make `public/assets/{sm,lg}/*.webp` from `../Proofed game assets/` (reads only) |
| `npm run data` | Regenerate `game-data.json` and `SPEC.md` from `gen_data.py` |

## Code map

- `src/engine/`: pure TypeScript rules engine, no React. The game is `replay(actions)`; Undo drops the last action.
- `src/store.ts`: the action log, autosaved to `localStorage` after every action.
- `src/screens/`: Home, Setup, the main screen, end of game, teacher menu; `flows/` holds the sheets (dice, landing, cards, Payday, Record).
- `src/ui/`: shared pieces (art, money, note helper, Settle up, dice, number pad).

## On the iPad

Open the site in Safari, tap Share, then **Add to Home Screen**. It then opens full screen and works offline. The teacher menu opens when you press and hold the logo for 2 seconds.

## Deploy (Vercel)

Root Directory `companion-app`, Framework Preset **Vite**, Build Command `npm run build`, Output Directory `dist`.
